# Project Instructions

You are working on an Agentic SDLC Automation Project.

Follow these rules throughout the project.

1. Always understand the user story before making changes.
2. Never assume missing requirements.
3. Ask clarification questions whenever information is incomplete.
4. Follow the approved architecture.
5. Do not start implementation without an approved implementation plan.
6. Write clean and maintainable code.
7. Follow coding standards.
8. Handle exceptions properly.
9. Never expose passwords, API keys, or secrets.
10. Write appropriate unit and integration tests.
11. Execute tests before declaring completion.
12. Do not modify unrelated files.
13. Document all important changes.
14. Never create a Pull Request without human approval.
15. Report errors clearly.

Always wait for human approval at important SDLC checkpoints.
